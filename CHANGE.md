## 2026-11-01

- Set paper backups to 8 × 13 inch portrait. Faculty can set the printed total points; points are distributed across questions in proportion to their current values, and the online activity scoring is unchanged.
- Added small monochrome print icons to student identity fields and code scaffold/response labels as scan cues, keeping paper copies text-first and printer-friendly.
- Added a shared, visible request indicator across Student, Faculty Studio, and Proctor, with action-specific labels for sign-in, saving, generation, validation, publishing, grading, exports, and monitoring. Background proctor refresh shows inline progress without interrupting the screen. Rebuilt the paper-copy layout using a same-origin print stylesheet: 8 × 13 inch portrait, wider content area, locally bundled OFL Poppins text, Consolas code, repeated table headers, and a visible preparation state while fonts load.
- Added an optional, collapsible 2,000-character custom AI prompt in Faculty activity setup. Guidance can shape context, coverage emphasis, style, and reasoning depth; it cannot override source grounding, question limits, supported types, or answer privacy. Changes after preview mark it stale and require a new generation. The custom prompt is kept with recoverable faculty previews and is not copied into the published student package.
- Added Faculty Studio paper backups. Faculty can print a student version without answers or a separate faculty answer key, then save either as PDF for an outage. Student sheets include name/School ID fields, response areas, full reference datasets, column indexes, and code scaffolds for DataTables missions.
- Added safe answer retries using a stable per-answer idempotency key. If a request reaches the server but its response is lost, retrying the same answer returns the original attempt and does not charge another retry or time penalty. Added private, server-saved answer drafts that restore after reload and clear on submission. Faculty Results now offers audited time extension and attempt reopening with a required reason, limited to 1–120 minutes before the run closes. Added Store and HTTP integration coverage for these paths. The supervised pilot remains skipped. Full suite: 64/64 passed; legacy SQLite migration and integrity were verified on a temporary copy of the baseline backup.
- Programming questions now render fenced PHP, SQL, JavaScript, and Python snippets as code blocks in student questions and faculty review, preserving indentation and syntax colors. Inline backticks also render as code. AI draft instructions request real fenced snippets rather than code flattened into paragraphs; the question editor accepts the same format. Older published prompts remain unchanged until revised in an editable copy.
- Extended the lightweight student code coloring to PHP, SQL, JavaScript, and Python, with a display-only syntax selector. DataTables questions continue to parse and grade JavaScript. Added token tests for all four languages.
