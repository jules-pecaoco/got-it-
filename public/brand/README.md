# Application assets

`favicon.svg` is a simple G monogram for Got It!, using the application's blue
(`#182E7B`) and gold (`#FDC800`) palette. It is independent of any university logo.

Branding and headings use locally served Poppins from `../fonts/`, distributed
under the included SIL Open Font License. Forms, navigation and data use Segoe UI
or the system sans-serif; source code and terminals use monospace.

See the [branding reference](../../docs/reference/BRANDING.md) for theme rules and
the [documentation contents](../../docs/README.md) for the rest of the guides.
